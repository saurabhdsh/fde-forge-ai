# Healthcare Governance Note

FDE Forge AI is a **workforce training** platform.

- AI-generated healthcare content requires human SME and compliance review before publish (Phase 3+).
- Content is educational and **not medical advice**.
- Learner responses must not be treated as clinical decisions.
- Regulatory references must include source and version when authored.
- Production customer or PHI data must not be uploaded without authorization.

Content classifications (General, Internal, Confidential, Restricted, PHI-sensitive, GxP-controlled) will gate access in later phases.
