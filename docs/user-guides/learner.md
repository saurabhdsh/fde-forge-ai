# Learner Guide (Phase 1–2 + domain courses)

1. Sign in with username (e.g. `Saurabh`), password, and organization slug `acme-health`.
2. Open **My profile**.
3. Set target FDE role, hours, domain preferences (Healthcare / Life sciences / Technical), and accept privacy + AI processing consents.
4. Upload a PDF or DOCX resume.
5. Review AI-extracted skills, edit as needed, and confirm.
6. Open **Skills** to view your skill profile.
7. Open **Courses**, select topic widgets for each domain (Healthcare / Life sciences cover the broad domain map), then generate/complete one super-course per domain (needs `OPENAI_API_KEY`). Org admins may upload PDF/DOCX source docs that also enrich generation. Assessment stays locked until every required course is completed.
8. Open **Assessment** and start the baseline quiz (requires confirmed skills + completed domain courses + `OPENAI_API_KEY`). Save progress or export as needed.
9. Open **Coding lab** (parallel track after courses) for 25+ hard Python GenAI/agent coding challenges; type solutions and submit for AI grading.
10. Use **Home** to track course, assessment, and coding progress. Admins use Interview readiness when MCQ and Coding are both ≥70%.
